# Gwent Tally

Gwent Tally is a simple Android companion app for tracking your side of a
Gwent battlefield. Add units to the Close Combat, Ranged, and Siege rows, then
adjust their strength and abilities while the app calculates the current total.

## Features

- Track units across all three battlefield rows
- Adjust each unit's base strength
- Mark units as heroes, spies, berserkers, morale units, or tight-bond units
- Assign tight-bond groups
- Apply Commander's Horn to individual rows
- Apply weather effects:
  - Biting Frost
  - Impenetrable Fog
  - Torrential Rain
  - Skellige Storm
- Apply Mardroeme and double spy strength
- Use Scorch to remove the strongest eligible units
- Clear weather or reset the complete battlefield
- Display row totals, total strength, and each unit's effective strength

## Technology

- Kotlin
- Android
- Jetpack Compose
- Material 3
- Gradle version catalogs

The app uses a single Android application module and has a minimum Android SDK
version of 26.

## Getting started

1. Go to Actions and open the latest workflow run and download the `app-debug.apk` artifact.
2. In order to install the APK on your Android device, you may need to enable "Install unknown apps" in your device's settings.
3. Run the APK on your device.
4. Launch the app and start tracking your Gwent battlefield.
